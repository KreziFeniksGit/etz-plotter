# Home toner transfer PCB rules

For home-etched single-sided boards: traces >= 0.5 mm (we use 0.6), clearance >= 0.4 mm, 2 mm+ through-hole pads, ring >= 0.5 mm,
thermal spokes on pour pads, no copper text under ~2 mm, fill empty areas with ground, print a test coupon first.
