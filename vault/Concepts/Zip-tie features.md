# Zip-tie features

One entry in `W.ZIPS` / `frame.ZIPS` cuts the slot pair and places the tie, so they always match. Slots sit either side of the
cable (v2.5 fix: they were turned 90 deg and a tie could not wrap the cable). Related: [[Design rules (DFM)]], [[Cable chains and harness]].
