# Firmware defaults must meet the rules

**What happened:** The firmware default speed 3200 steps/s = 40 mm/s is below the ETZ minimum of 100 mm/s; the twin happily ran slow.

**Rule:** Defaults that a rule constrains must satisfy it; the run program also sets speeds every run.
