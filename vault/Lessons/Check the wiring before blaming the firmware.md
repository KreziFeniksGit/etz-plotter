# Check the wiring before blaming the firmware

**What happened:** 25 Oct: "motor still shaking" looked like the new own-library firmware was broken; it was a loose motor connection. Time was spent comparing with the old firmware.

**Rule:** Shaking / no motion: first check the coil pairs and connectors, VM power, driver `status`; then the code.
