# The twin finds real bugs before the hardware exists

**What happened:** 29 Oct, random tasks on the twin found: picks aimed at the snapped cell centre, drops onto cells half-covered by an off-centre neighbour, clamped-pick carry offset not compensated (also after a wrist turn). 30/30 after fixes.

**Rule:** Test new laptop logic on many random twin tasks, with sheet offset and detection noise, not only the happy example.
