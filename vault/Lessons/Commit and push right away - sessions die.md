# Commit and push right away - sessions die

**What happened:** 16 Oct: a finished MG996R revert sat uncommitted for days because the session died; Egor's other devices had the old model.

**Rule:** Commit and push after every finished change whose checks are clean, without asking. The stop hook reminds when tracked changes are left.
