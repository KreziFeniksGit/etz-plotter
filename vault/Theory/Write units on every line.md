# Write units on every line

**Seen:** Mock 0 / 01: 9 rad never converted to turns, an extra ×2; set 03 / 6: m/s² given where cm/s² was asked; 09: divided by 20 twice.

**Rule:** Write the unit after every number; before typing the answer, reread what exactly is asked and in which unit.
