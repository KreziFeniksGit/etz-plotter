# Theory exam format

8-10 tasks: 6-8 calculation tasks (only the final number is typed into the testing system, no live check, typos are not fixed) +
2 programming tasks (C++ or Python, auto-tested in Yandex Contest, results live). Non-programmable scientific calculator allowed.
Paper = drafts only. Time limits apply to Python too (Egor's solution once took 1.03 s on a 1 s limit) - [[Count operations before writing code]].
