# Lever arm is the perpendicular distance

**Seen:** Set 03 / 1: sin 60° instead of cos 60°; set 02 / 3: arm measured from the mast, not the wheel; Mock 0 / 04: h·cos θ instead of h·sin θ.

**Rule:** Draw the force line, drop a perpendicular from the pivot; angle above the horizon -> arm = L·cos α. Torque is about the point the body turns around.
