# Count operations before writing code

**Seen:** Set 03 / 7: naive grid sums correct but 20 queries took 2.7 s; 10^5 queries hopeless. A real Python run hit 1.03 s on a 1 s limit.

**Rule:** Estimate n × queries before coding; ~10^7 simple Python operations per second. If too slow, precompute ([[Prefix sums]]).
