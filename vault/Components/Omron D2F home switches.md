# Omron D2F home switches

D2F-01L microswitches with lever, X and Y, on GPIO38/48 with pull-up, wired NC so a broken wire reads "pressed" (safe).
Repeatability better than generic KW10. Used by [[Homing and soft limits]]. Bench trick: a jumper to GND = "not pressed".
Related: [[GPIO38 and GPIO48 are inputs only]].
